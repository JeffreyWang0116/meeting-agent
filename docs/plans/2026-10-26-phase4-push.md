# 第四階段：手機推播提醒（#13）

## 問題

目前的「每日提醒通知」用的是頁面端的 `new Notification(...)`（`app/static/js/reminders.js`）。
這在手機上幾乎等於沒有：

- **iOS 完全收不到。** Safari 與加到主畫面的 PWA 都不支援在頁面裡 `new Notification()`；
  iOS 16.4 起只支援「已加入主畫面」＋ service worker 的 `registration.showNotification()`。
- **要開著才會跳。** 就算在桌面瀏覽器能跳，也只在使用者自己打開 App、而且跑到
  `refreshReminders()` 時才會發生——那時他已經看到提醒清單了，通知沒有意義。

真正能用的提醒必須是：App 關著、手機鎖著，時間到了自己跳出來。那只有 Web Push 做得到。

## 做法

Web Push（VAPID，RFC 8292）＋ service worker ＋ 外部排程。

```
GitHub Actions（每小時）
   └─ POST /api/push/run   X-Push-Secret: ...
        └─ 掃所有訂閱 → 該送的（當地時間到了、今天還沒送）
             └─ pywebpush → FCM / APNs → 手機
                  └─ sw.js 的 push 事件 → showNotification
```

### 為什麼要外部排程

Render 免費方案沒活動就休眠，`asyncio` 的背景排程器睡著就不會醒。
GitHub Actions 的 cron 是免費且獨立於本服務的，順便兼具喚醒作用。

### 時區

訂閱時把瀏覽器的時區存下來（`tz_offset`＝比 UTC 快幾分鐘，台北＝+480），
排程每小時跑一次，對每個訂閱換算成當地時間再決定要不要送。

送出條件是「當地時間落在 9:00–11:59 且今天還沒送過」，而不是「剛好等於 9 點」：
GitHub Actions 的 cron 常常延遲十幾分鐘到一小時，卡死在整點會讓某些日子整天不送。

### 推播內容不放任務文字

只放數量（「3 項逾期、1 項今天到期」）。推播會顯示在鎖定畫面上，
而鎖定畫面是旁邊的人也看得到的地方；任務內容往往帶人名與金額。

### 訂閱綁哪個工作區

訂閱記下「訂閱當下的工作區」（個人 uid 或 `group:<id>`）。
切換工作區時若通知是開著的，就重新訂閱一次覆蓋掉。
一個瀏覽器只有一組 endpoint，所以不可能同時訂兩個工作區——
與其做複雜的多訂閱，不如讓它跟著使用者當下在看的那一個。

### 失效的訂閱

推播服務回 404 / 410 代表對方已經解除安裝或清掉網站資料，直接刪掉那筆訂閱，
不然死訂閱會永遠留在資料庫裡每小時被試一次。

## 檔案

| 檔案 | 內容 |
|---|---|
| `app/push.py` | 純邏輯：訂閱驗證、id、時間判斷、摘要文字；以及真正送出的 sender |
| `app/stores/*` | `save/list/delete/all_push_subscriptions` |
| `app/main.py` | `/api/push/key`、`subscribe`、`unsubscribe`、`test`、`run` |
| `app/static/sw.js` | `push` 與 `notificationclick` |
| `app/static/js/push.js` | 設定頁開關、iOS 未加入主畫面的引導 |
| `.github/workflows/push-reminders.yml` | 每小時 cron |

## 環境變數

| 名稱 | 說明 |
|---|---|
| `VAPID_PUBLIC_KEY` | 公鑰（base64url，前端拿得到） |
| `VAPID_PRIVATE_KEY` | 私鑰（base64url 的 32 bytes raw） |
| `VAPID_SUBJECT` | `mailto:...`，推播服務要求的聯絡方式 |
| `PUSH_CRON_SECRET` | `/api/push/run` 的通關密語 |

四個都沒設＝功能停用，前端開關會說「這個站台沒有設定推播」。

## 驗收

1. iPhone 用 Safari 開 → 分享 → 加入主畫面 → 從主畫面開啟 → 設定裡開啟通知 → 允許
2. 按「試送一則」→ 手機跳出通知
3. 完全關掉 App（從多工列滑掉）→ 再按一次試送 → 還是跳得出來
4. 點通知 → 開回 App
