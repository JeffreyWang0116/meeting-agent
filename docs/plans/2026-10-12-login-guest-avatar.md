# 工作區切換不再跳登入、訪客登入、頭像選單

日期：2026-10-12

## 問題
個人／群組切換時一直跳出登入畫面。根因有兩個：
1. 切換工作區用整頁重新載入（上一版為了保險）
2. 重新載入時登入畫面在 Firebase SDK 載完、恢復登入狀態**之前**就先蓋上來；手機下載 SDK 常要
   1~3 秒。不保存登入狀態的環境（LINE 內建瀏覽器、Safari 無痕）則是真的每次都要重登

## 決策紀錄（使用者 2026-10-12 核准）
- 訪客：Firebase 匿名登入，資料照常存進資料庫，「離開訪客」時刪除（需在 Firebase 開啟匿名登入）
- 訪客可用全部功能，速率限制依連線 IP 計算、額度約登入者的三分之一（`GUEST_RATE_LIMITS` 可調）
- 主畫面右上角頭像：顯示帳號、切換帳號、登出（訪客為「改用 Google 登入」「離開訪客」）

## 任務
1. 驗簽回傳 guest 旗標（sign_in_provider == anonymous）；中介層記 CURRENT_GUEST／CURRENT_IP；
   `GUEST_LOGIN_ENABLED=0` 時拒絕匿名 token
2. 速率限制：訪客走另一組上限，key＝ip:<IP>（取 X-Forwarded-For 最後一段：前段可由用戶端偽造）
3. `DELETE /api/guest/data`：只限訪客，刪掉自己的會議、任務、詞彙、講者名冊、問答索引
4. 訪客不能用群組（403）
5. 前端：登入畫面先顯示「載入中」，確定沒登入才出現；Google／訪客兩個選項；頭像選單；
   工作區切換改成就地切換（各模組監聽 workspacechange 重設快取並重抓），聆聽或上傳中不給切
6. README、測試、瀏覽器驗證
